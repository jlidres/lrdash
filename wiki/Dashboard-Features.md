# Dashboard Features

## Filters

The dashboard supports filtering by:
- school
- category
- type
- status
- grade level
- learning area
- free-text search

Use **Reset filters** to clear all filter inputs.

## Metrics

Top cards show filtered totals for:
- visible records
- visible quantity
- schools represented
- distributed share
- in-stock quantity
- latest update timestamp

## Charts

- Quantity by school
- Quantity by status
- Top material types
- Monthly received quantity

## Tables

- Largest in-stock items
- Latest updates
- Filtered inventory detail rows

## Export

Use **Export filtered CSV** to download the currently filtered records.
