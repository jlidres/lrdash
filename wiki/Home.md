# LR Dashboard Wiki

Welcome to the LR Dashboard wiki.

This dashboard provides a live and snapshot-backed view of the LRMS inventory sheet, including:
- summary metrics
- filterable resource inventory views
- operational charts
- CSV export of the filtered dataset
